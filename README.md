# Hangman

Консольная реализация классической игры «Виселица» на Java.

## Возможности

- Случайное слово из словаря русских существительных (длина от 5 до 9 букв)
- ASCII-виселица, которая дорисовывается после каждой ошибки
- Показ уже введённых неверных букв
- Валидация ввода: принимается одна русская буква в любом регистре, при неверном вводе запрос повторяется и ошибка не засчитывается
- Повторный ввод буквы (верной или неверной) не считается новой ошибкой
- Возможность сыграть новый раунд после победы или поражения
- Непредвиденные ошибки записываются в `log.txt`, игроку выводится короткое сообщение

## Технологии

- Java 23
- Maven

## Запуск

Требования: JDK 23.

```bash
git clone https://github.com/MakeOren/Hangman.git
cd Hangman
```

### Через IntelliJ IDEA

1. Откройте папку проекта (файл `pom.xml` будет подхвачен автоматически).
2. Дождитесь загрузки Maven-проекта.
3. Запустите класс `io.github.MakeOren.Hangman`.

### Через Maven в терминале

Требуется установленный Maven.

```bash
mvn compile
java -cp target/classes io.github.MakeOren.Hangman
```

Запускать нужно из корня проекта: файл словаря `dictionary.txt` читается по относительному пути.

> **Примечание для Windows.** В классической консоли Windows ввод кириллицы может работать некорректно из-за кодировки консоли: корректные буквы будут отклоняться как неверный ввод. В этом случае запустите игру из IntelliJ IDEA.

## Как играть

1. Введите `1`, чтобы начать новую игру, или любой другой символ, чтобы выйти.
2. Угадывайте слово, вводя по одной русской букве.
3. Игра проиграна после 6 неверных букв.
